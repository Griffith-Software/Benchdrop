Autotest

Benchdrop clicks through the running app, fills in forms and follows its navigation, and logs anything that breaks: console errors, uncaught exceptions, failed requests, crashes. At the end you get a report with the steps that led to each problem.

It tries every control it can reach, fields before buttons. To test toward a goal, or have screens judged as well, connect Claude (Help → Connect to Claude…) and ask it.

Connect to Claude

Let Claude open, run and test projects in Benchdrop for you, from a conversation in Claude Desktop or Claude Code. It uses your own Claude account — there's no API key to set up.

Claude Desktop

In Claude Desktop, open Settings → Extensions, then drag benchdrop.mcpb onto that page. Claude Desktop shows what it does and asks you to confirm.

Claude Code

Run this once in a terminal:

It won't appear in Claude Desktop's Settings → Extensions — that list is only for Claude Desktop. To check it's there, run claude mcp list, or ask Claude in Claude Code what Benchdrop tools it has.

Claude can open and run projects, read the screen, click, type, take screenshots, read the log and run Autotest. Benchdrop refuses anything risky (delete, pay, send, log out…), never types into password or secret fields for it, never follows links out of the app, and doesn't run commands for it. Everything Claude does appears in the log, marked [claude].
